Project Overview

A short guide to how SPAAMS keeps academic records accurate and useful.

01 / Records start with the right context

Set up a batch

Administrators create faculties, semesters, subjects, and academic batches. This keeps a 2023 third-semester class separate from a later third-semester batch.

02 / Work only with assigned learners

Record class activity

Teachers see the students in their assigned subject, semester, and batch. They can record assessment marks and daily attendance for that roster.

03 / Use saved records

Review progress

Dashboards use the marks and attendance already saved in the database. Students and staff see current data rather than placeholder values.

04 / Focus attention where it is needed

Follow up early

Attendance and performance indicators make it easier to identify students who may need academic support or attendance follow-up.

A smarter way to monitor performance, attendance and help students achieve excellence.
